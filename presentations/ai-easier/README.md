# AI로 편해지는 중 (손글씨 노트 덱 · 19장 + 데모 영상)

화성 EHS팀 3분기 소통회 (2026-10-07 10:30, 225명, 20~25분). 비개발·AI 저활용 청중 대상.
자기소개는 말로 하므로 자료에 없음.

척추 문장: **"일은 그대로여도 편해질 수 있다 — 내용만 채우면 나머지는 공장이 찍는다."**
은유는 '공장' 하나 — 원료(내용·자료) · 금형(잘 만든 견본) · 출고 전 검사(사람 눈, 특히 숫자).
수미상관: 2장 "그래서, 편해져요?" ↔ 19장 로봇 말풍선 + "편해지는 건 확실".
②의 핵심: 입력은 몇 줄이지만 완성은 몇 바퀴 — 바퀴는 AI가 돌리고 판단은 사람이 (10장 루프 + 11장 실제 녹화).

어투 조건(발표자 지시): 의도가 뻔한 구성 금지(목차·DX/AX 정의·"AI 오해" 장 없음), "~였다"류 AI 말투 금지,
코딩은 "가장 먼저 좋아진 영역"으로, 제목에 "나부터" 금지, 화면에는 HTML 대신 PPT·PDF·워드 같은 익숙한 말.
짧은 발표라 구간 디바이더 없이 각 구간 첫 장에 작은 구간 태그(①~④)만 단다.

- `index.html` — 이미지 뷰어 (←/→/Space/Home/End, `F` 전체화면, 터치 스와이프, `#N` 딥링크) + 11장 데모 영상
- `NN-slug.webp` — 슬라이드 19장 (1672×941, q95, 총 3.0MB, 종이색 #FCF8F2로 통일)
- `demo.mp4` — 제작 과정 녹화 (git 제외, Firebase로만 배포)
- `deck-spec.json` — 장별 프롬프트·레퍼런스 (재생성 정본)
- `src-png/` — 원본 PNG 1376×768 (git/배포 제외): `_prenorm/` 배경 보정 전, `_v1/` 21장판, `_v2/` 18장판,
  `_orig/` 국소 수정 전, `_fix/` 수정 프롬프트, `logs/`

## 데모 영상 (`demo.mp4`)

- 원본: oCam 녹화 `녹화_2026_10_02_22_32_18_243.mp4` (26분 52초, 2544×1384, 음성 트랙 없음, 175MB) — 원본은 그 자리에 둠.
- 가공: 17.9배속 → 90초, 소리 제거, 1600×870 · 30fps · H.264 CRF 26 · faststart → 9.2MB.
  앞 9초(원본 기준)는 잘라냈다 — 녹화 시작 때 터미널이 이전 대화로 스크롤돼 있어 API 키가 들어간 구간을 지나가기 때문.
  최종 89.5초.
- 뷰어: 11장에 들어가면 음소거 자동 재생, 나가면 일시정지. `P`로 재생/정지, 영상 컨트롤로 전체화면.
  파일이 없으면 그림 속 ▶ 아이콘만 보인다.
- 영상 자리는 11-demo 원본(1376×768)의 화면 안쪽 x 324–1053, y 240–610 — `index.html`의 `DEMO_BOX`.
- `.gitignore`에 있어 git엔 안 올라가고 `firebase deploy`로만 올라간다. 다시 만들 때:

```bash
ffmpeg -i <녹화.mp4> -an -vf "setpts=PTS/<원본초÷90>,fps=30,scale=1600:-2:flags=lanczos" \
  -c:v libx264 -preset slow -crf 26 -maxrate 2500k -bufsize 5000k -pix_fmt yuv420p -movflags +faststart demo.mp4
```

## 이미지 생성·후처리 재현

- 엔진: **note-deck-openrouter** — OpenRouter `google/gemini-3.1-flash-image`, 네이티브 1376×768.
- 프롬프트: note-deck `references/prompts.md` STYLE 블록 + 레이아웃 레시피 (로봇 묘사만 레퍼런스에 맞춰 조임).
- 레퍼런스: 레이아웃별 ax-why-hard 1장(발표자가 고른 톤 — 03·07) + 이 덱의 01-title(앵커),
  다시 그린 장은 직전 판도 함께. cover=ax 01+03, cards=ax 17, flow=ax 11, contrast=ax 07, stat=ax 08, banner=ax 13.
- **배경 통일**: `normalize_bg.py`가 장마다 종이색을 부드러운 필드로 추정(1/8 축소 80퍼센타일)해 나눠서
  모든 장의 종이를 #FCF8F2(뷰어 배경과 동일)로 맞춘다. 보정 전 장별 (249,242,228)~(255,255,245) → 보정 후 전부 (252,248,242)±1.

```bash
python ~/.claude/skills/note-deck-openrouter/scripts/gen_openrouter.py deck-spec.json --only 10-loop
python ~/.claude/skills/note-deck-openrouter/scripts/gen_openrouter.py --one src-png/X.png --prompt-file src-png/_fix/X.txt --ref src-png/_orig/X.png --edit
python ~/.claude/skills/note-deck-openrouter/scripts/normalize_bg.py presentations/ai-easier      # --check 로 측정만
python ~/.claude/skills/note-deck/scripts/encode_webp.py presentations/ai-easier
python ~/.claude/skills/note-deck/scripts/verify_deck.py presentations/ai-easier
```

이미지는 `immutable` 캐시라 내용이 바뀐 장은 파일명을 바꿔야 한다 (v2·v3에서 번호·슬러그를 바꿔 처리).
