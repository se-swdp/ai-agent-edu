# AI로 편해지는 중 (손글씨 노트 덱 · 21장)

화성 EHS팀 3분기 소통회 (2026-10-07 10:30, 225명, 20~25분). 비개발·AI 저활용 청중 대상.
자기소개는 말로 하므로 자료에 없음.

척추 문장: **"일은 그대로여도 편해질 수 있다 — 내용만 채우면 나머지는 공장이 찍는다."**
은유는 '공장' 하나 — 원료(내용·자료) · 금형(잘 만든 견본) · 출고 전 검사(사람 눈, 특히 숫자).
②가 금형, ③이 원료, ④가 검사를 맡고 클로징 질문 셋이 셋을 다시 부른다.

어투 조건(발표자 지시): 의도가 뻔한 구성 금지(목차·DX/AX 정의·"AI 오해" 장 없음), "~였다"류 AI 말투 금지,
코딩은 "가장 먼저 좋아진 영역"으로, 제목에 "나부터" 금지, 청중 화면에는 HTML 대신 PPT·PDF·워드 같은 익숙한 말.

- `index.html` — 이미지 뷰어 (←/→/Space/Home/End, `F` 전체화면, 터치 스와이프, `#N` 딥링크)
- `NN-slug.webp` — 슬라이드 21장 (1672×941 업스케일, q95, 총 3.0MB)
- `deck-spec.json` — 장별 프롬프트·레퍼런스 (재생성 정본)
- `src-png/` — 원본 PNG 1376×768 (git/배포 제외), `_orig/` 수정 전 판, `_fix/` 수정 프롬프트, `logs/` 비용·프롬프트
