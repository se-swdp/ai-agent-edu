# AX는 왜 어려울까 (손글씨 노트 덱)

척추 문장: **"에이전트는 만들기 쉽고 신나지만 — 쓰이고 운영되는 건 다른 일이다. 쓸 사람과 굳은 길이 먼저."**

어투 규칙: 만드는 사람에게 공감하는 톤 — 발표자 자신도 포함("나도 그랬다"). 빌더를 조롱하지 않는다.

Tone: 혼내지 않고 스스로 떠올리게 — 섹션 끝마다 '내 에이전트' 포스트잇 (08 · 13 · 20 · 24), 클로징에서 네 장을 다시 모아 회수. 청중 = 지금 에이전트를 만드는 사람.

2026-09-29 제작. 노트필기 스타일 **본편 26장 + 부록 1장** 이미지 덱.
1차 기획(25장, 척추 "AX는 일하는 방식의 문제…")에서 같은 날 재설계 — 재설계 전 생성본은 새 순번으로
재명명해 재사용하고, 대체된 원본은 `src-png/_cut/`에 보존.

텐션 곡선: 훅(30년 운영 서버) → 에이전트의 매력 · 만들 때의 나(공감) → ① 그런데, 누가 쓸까(거울 질문 · 믿음 vs 현실 · 숫자)
→ ② 순서가 뒤집혔다 → 소결 "배포는 쉽고, 운영은 어렵다" → ③ 운영의 두 벽(권한 · 지식)
→ 클라이맥스 "인지는 유한하다" → ④ 길이 나면 포장한다 → 클로징(쓸 사람이 먼저 · 섭종 계획, 훅 회수) → 부록.
