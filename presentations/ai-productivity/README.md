# AI로 생산성은 어떻게 올랐나 (손글씨 노트 덱 · 21장)

화성 EHS팀 3분기 소통회 (2026-10-07 10:30, 225명, 20~25분 + Q&A). 비개발·AI 저활용 청중 대상.
자기소개는 말로 하므로 자료에 없음.
같은 소통회용 ai-easier("AI로 편해지는 중", 18장)를 발표자 지시로 다시 기획한 덱이다. ai-easier는 내용이 겹쳐 2026-10-04 삭제했다(git 기록에 남음).

척추 문장: **"워크플로우는 한 번 짜 두고 — 매번 넣는 건 내용만."** (9장 배너)
답의 구조(발표자 지시): 바로 좋아진 것(코딩) · 생각과 달리 늘어난 것(보고 판단할 일) · 줄지 않은 것(일 자체) ·
끝이 없는 것(효율화할 거리). 6·7·16장이 하나씩 보여 주고 20장이 한 장에 모은다.
수미상관: 2장 "그래서, 생산성은 올랐나?" ↔ 20장 "그래서, 생산성은?" 답 카드 넷.
텐션: 낙관(PoC → 기본 툴, 코딩) → 마찰(일은 그대로, 머리 쓸 일은 늘어남) → 해법(워크플로우) → 확장(자료 연결)
→ 마찰(숫자, 잘하기는 어려움) → 소양 → 답 → Q&A.
은유는 쓰지 않고 **워크플로우·템플릿**을 말 그대로 쓴다 (v4까지의 '공장' 은유 폐기, 발표자 지시).

어투 조건(발표자 지시): 의도가 뻔한 구성 금지(목차·DX/AX 정의·"AI 오해" 장 없음), "~였다"류 AI 말투 금지,
코딩은 "가장 먼저 좋아진 영역"으로, 제목에 "나부터" 금지, 화면에는 HTML 대신 PPT·PDF·워드 같은 익숙한 말.
재기획 조건: "편해져요" 대신 생산성·업무 효율, "괴로웠던" 대신 오래 걸리고 품이 드는 느낌, "해방" 금지,
"번진 길" 같은 상투어 금지, 너무 쉽게 풀지 않아도 됨(워크플로우 단계·Python 같은 말 그대로 사용).
짧은 발표라 구간 디바이더·구간 번호 없이 장 제목과 부제만으로 흐름을 잇는다.

- `index.html` — 이미지 뷰어 (←/→/Space/Home/End, `F` 전체화면, 터치 스와이프, `#N` 딥링크)
- `NN-slug.webp` — 슬라이드 21장 (1672×941, q95, 총 3.7MB, 종이색 #FCF8F2로 통일)
- `deck-spec.json` — 장별 프롬프트·레퍼런스·채택 후보(`picked`) (재생성 정본). `deck_dir`·`style_refs`는 레포 루트 기준 상대경로이고, 레퍼런스는 전부 git에 있는 파일이다
- `src-png/` — 원본 PNG 1376×768 (git/배포 제외): `_prenorm/` 배경 보정 전, `_v5cand/` 후보 spec·프롬프트
  (`cand-spec.json`, `edits/*.txt`, `r2/`). 버린 후보 PNG는 2026-10-04에 정리했다

## 이미지 생성·후처리 재현

- 엔진: **note-deck-openrouter** — OpenRouter `google/gemini-3.1-flash-image`, 네이티브 1376×768.
- 프롬프트: note-deck `references/prompts.md` STYLE 블록 + 레이아웃 레시피 (로봇 묘사만 레퍼런스에 맞춰 조임).
- 레퍼런스: 레이아웃별 ax 1장(`.claude/skills/deck-authoring/assets/layout-refs/ax-*.webp`) + 앵커 01-cover + 다시 그릴 장은 그 장의 현재 webp.
  (생성 당시엔 ai-easier v4 01-title이 앵커, v4의 같은 장이 장별 레퍼런스였다 — ai-easier 삭제 후 이 덱 파일로 교체)
  cover=ax 01+03, cards=ax 17, flow=ax 11, contrast=ax 07, stat=ax 08, banner=ax 13.
- **후보 비교**: 바뀐 17장마다 같은 프롬프트로 3장(a·b·c)을 뽑고, 문구만 바뀐 10장은 v4 원본에서
  Recipe 3 국소 수정(e)을 1장 더 뽑아, 4장 비교 시트로 고른 뒤 채택본을 원본 해상도로 다시 검수했다.
  각 장의 채택 후보는 `deck-spec.json`의 `picked`에 있다. 걸러낸 이유: 오타("매발자로서", "고르치기", "고르 고치기",
  지어낸 단어 "훈조비"), 줄 중복(같은 불릿 두 번, "알아서 알아서"), 앵커에서 딸려 온 "같이 편해지자!" 말풍선,
  배너 문구 누락, 다른 모양의 로봇, 부제가 카드 탭 사이에 끼는 배치.
- 14장은 1차 후보 넷이 모두 부제를 탭 사이에 끼워 그려서, v4 14장을 레퍼런스에서 빼고 "부제는 탭 위"를 명시해
  2차로 3장(r1~r3)을 더 뽑고, r3의 빠진 글머리 점을 국소 수정(`_v5cand/r2/fix14.txt`)으로 채웠다.
- 9장 부제는 레퍼런스(v4 9장) 영향으로 세 후보 모두 v4 문구 "가장 가벼운 예시"로 그려져, 그 문구를 그대로 채택하고
  spec도 맞춰 고쳤다.
- **배경 통일**: `normalize_bg.py` — 보정 후 21장 전부 (252,248,242)±1.
