# 뉴스 브리핑 글쓰기 가이드

`news/issues.json` 이슈를 쓰거나 고칠 때 본다. 예문은 7호(2026-10-12) 고치기 전 → 고친 뒤. 스키마·그림 절차는 `js/news.js` 상단 주석과 `news/img/STYLE.md`.

## 기본 규칙

- 주어는 사람이나 기관, 동사는 실제로 일어난 일. "누가 언제 무엇을 했다"로 쓴다.
- 평가는 말한 사람 이름을 붙이거나 뺀다. 숫자에는 출처와 기준 시각을 붙인다.
- 문단은 2~4문장, 250자 안쪽. 짧은 문장("유형은 넷이다.")을 섞는다.
- 제목은 사실을 담은 헤드라인. 요점은 한 줄에 사실 하나.
- 인트로는 장면이나 인용으로 열고, 교훈이 아닌 사실로 닫는다.

## 1. AI 말투 목록

### 추상명사에 몸이 있는 동사를 붙이기 (가장 먼저 지운다)
숫자·제도·시장이 흔들리고, 미끄러지고, 무겁고, 움직이고, 물러서면 고친다. 실제 주체와 실제 행동으로 바꾼다.

| 고치기 전 | 고친 뒤 |
|---|---|
| 매출 숫자가 흔들리자 AI주가 한꺼번에 미끄러졌다. | 이날 나스닥은 1.25%, 코어위브는 8% 내렸다(실리콘앵글). |
| 실물 쪽 숫자는 여전히 단단하다. | TSMC의 9월 매출은 5,119억 대만달러로 1년 전보다 54.6% 늘었다. |
| 제도는 22일 만에 한 발 물러섰다. | 협회 이사회는 25일 기준을 철회했다. 발표 22일 만이다. |
| 규제는 숲과 법정에서 먼저 움직였다. | 핀란드 당국은 7일 구글 자회사의 데이터센터 공사에 중단 명령을 내렸다. |
| 교실과 법정의 숫자는 무겁다 | 딥페이크 성범죄 기소 인원은 2024년 62명에서 2025년 273명으로 늘었다. |
| 워싱턴은 단어부터 바꾸는 중이다 | 악시오스는 트럼프 대통령이 8일 'AI'라는 말을 쓰는 이들을 겨냥한 글을 올렸다고 보도했다. |
| 값싼 판정 시장이 열렸다. | 마이크로소프트와 클라우드플레어도 비슷한 '결정 모델'을 내놨다. |
| 상장을 앞둔 앤트로픽에도 회의론이 붙었다 | 버니 모레노 상원의원(공화)은 5일 아모데이 CEO에게 서한을 보냈다. |
| 정책은 국정감사에서 숫자로 다퉈졌다. | 배경훈 부총리는 6일 국정감사에서 … 이어가겠다고 했다. |

같은 계열: 가장 무거운 건 / 이미 물량의 문제다 / 창작자의 말에 기대고 있다 / 연말 출시로 정리됐다 / 그 흐름이 닿은 곡.

### 문단마다 볼드 논지 문장으로 열기
- 전: `**작은 모델은 10분의 1 값이 됐고, 챗GPT는 통째로 GPT-6로 넘어갔다.**`
- 후: "앤트로픽은 7일 클로드 하이쿠 5.5를 냈다. 100만 토큰당 입력 **$0.10** …"
- 볼드는 꼭지당 숫자 하나까지. 문장 전체를 굵게 하지 않는다.

### "A가 아니라 B" / "더 이상 ~만의 문제가 아니다"
- 전: 차트를 끌어올린 건 마케팅이 아니라 댓글이었다. → 후: 기획사 프로모션은 없었다. 노래는 쇼츠와 릴스 배경음악으로 먼저 퍼졌다.
- 전: 에이전트 이탈은 더 이상 오픈AI만의 문제가 아니다. → 후: 앤트로픽이 9일 자사 모델의 '비의도 행동' 조사 보고서를 냈다.

### 훈계하거나 요약하는 마무리
- 전: 「꿈꾸던 어른이 되었나요?」는 그 흐름이 처음 메이저 차트 상위권에 닿은 곡이고, 제도는 그 곡을 어떻게 부를지부터 정해야 한다.
- 후: 마지막 문장을 지우고 사실로 끝낸다. "텐센트뮤직은 신규 업로드 중 AI 곡 비중이 … 44.1%로 늘었다고 했다."
- 인트로도 같다. 전: "노래는 사람을 울리기 시작했는데, … 제도는 아직 빈칸이다." 후: "삼성전자의 3분기 영업이익은 107.4조 원(잠정)이다."

### 누가 했는지 없는 평가
- 전: 작곡은 'AI 보조'로 보는 게 정확하다. / 아직 수학계 기준엔 못 미친다는 평이다.
- 후: 데일리안은 이 곡의 작곡과 가창에 수노 같은 생성형 AI가 쓰였다고 썼다. / 테크크런치는 수학계 기준에는 아직 못 미친다고 보도했다.
- "~할 전망이다", "주목된다"도 같다. 전망한 주체를 쓴다: "세계일보에 따르면 업계는 3분기 반도체(DS) 부문 영업이익을 110조 원 가까이로 본다."

### 대시(—)로 문장 잇기
- 7호 원문에 20개. 이슈 전체에서 2개까지. 전: 오픈AI 사례 3건 추가 — 위키미디어 … → 후: 마침표로 끊어 문장을 나눈다.

### 날짜 셋 이상을 한 문장에
- 전: 7월 18일 … 넣은 일로, … 9월 28일에야 발견돼 10월 8일 경찰에 통보됐다 → 후: 하이쿠 4.5는 7월 18일 … 넣었다. 앤트로픽은 9월 28일에야 이를 발견했고 10월 8일 경찰에 알렸다.

### 그 밖에
- 추상 범주 라벨 요점: 전 "값과 화면 — 클로드 하이쿠 5.5(…), 챗GPT의 GPT-6 …" → 후 "클로드 하이쿠 5.5 출시, 100만 토큰당 입력 $0.10·출력 $0.50"
- 셋씩 묶는 나열, 모든 문장 길이가 같은 리듬, 한자어 명사 쌓기("AI 표기 의무화 논의 본격화")를 피한다.
- 지킬 것: 이름 붙은 인용, "(오픈AI 주장)" 같은 단서, 구체적 숫자.
- 사물 의인화도 같다. 전: 가사는 "잘 지내는 척"하며 … 묻는다 → 후: 가사 속 화자는 "잘 지내는 척"하지만 … 묻는다.
- '수량+의' 번역투. 전: 하루 약 9만 곡의 AI 트랙이 → 후: 하루에 올라오는 AI 곡이 약 9만 곡이라고.
- 꼭지 사이, 엇갈리는 평 사이에는 평범한 이음 문장을 둔다("임희윤 평론가는 다르게 봤다."). 은유·교훈은 넣지 않는다.

### 출처가 말한 만큼만 (7호 사실 검토에서)
- 출처에 없는 기준 시각을 붙이지 않는다. 전: 10월 2일 오전 8시 멜론 18위 → 후: 10월 2일 기준 최고 18위(CWN).
- 날짜·차트가 다른 순위를 한 집계로 묶지 않는다. 전: 톱스타뉴스의 8일 집계에서는 벅스 2위, 플로 5위 → 후: 벅스 일간 차트 2위(6일), 플로 5위(8일 오전 7시 기준).
- "~에 따르면" 문장에 그 출처에 없는 내용을 잇지 않는다. 출처가 다르면 문장을 나눈다.
- 예고 기사만 있으면 예고로 쓴다. 전: 국회에서 포럼이 열렸다 → 후: 데일리안은 … 토론회가 열린다고 예고했다.
- 인과는 출처가 말한 만큼만. 전: FT는 … 보도했고, 그날 나스닥은 1.25% 내렸다 → 후: 실리콘앵글은 장 초반부터 내리던 지수가
  FT 보도 뒤 낙폭을 키웠다고 전했다. 제목은 "보도 당일 … 하락"처럼 같은 날만 쓰고 "때문에"는 쓰지 않는다.
- 출처가 밝히지 않은 공제 항목·발언자는 지어내지 않는다. 발언자가 없으면 자리를 쓴다("국정감사에서는 … 지적도 나왔다").
- 확인 못 한 숫자는 뺀다(7호: 공식 영상 조회수, SK하이닉스 영업이익 전망치).

### 처음 읽는 사람 기준
- 전문용어는 처음 한 번만 풀어 쓴다. 하네스 → "모델에 도구를 붙여 돌리는 실행 틀(하네스)", 신탁 등록 →
  "(협회가 저작권료를 대신 걷는 계약)", MoE 규모 → "전체 1.05조 개 파라미터 중 한 번에 약 500억 개만 쓰는 구조".
- 한 글에서 같은 단어를 다른 뜻으로 쓰지 않는다. 전: 공개된 토큰으로 유료 데이터 조회 (뒤에 "100만 토큰당") → 후: 누구나 받을 수 있던 접근 키로.
- 숫자에는 비교 기준을 붙인다. 전: 전년 대비 +782.5% → 후: 1년 전의 약 8.8배. "안전·신뢰 274억 원" 뒤에 "전체 예산안의 약 0.3%다."
- 철회·종료된 제도는 과거형. 전: 신탁 등록을 받는다 → 후: 신탁 등록을 받겠다는 내용이었다.
- 같은 인용은 한 번만. 인트로에 쓰면 본문에서 빼고, 인트로 인용에도 출처를 단다.

## 2. AI 이미지 티

- 모든 카드가 왼쪽 글·오른쪽 그림 같은 틀. 모든 그림에 같은 그레인 질감, 전체에 깔린 노란 웜톤.
- 로봇, 빛나는 뇌, 스포트라이트, 반짝이, 네온. 지브리·애니풍 얼굴, 복제한 듯 같은 얼굴의 군중.
- 요소를 빽빽하게 채운 구도.
- 데이터를 왜곡하는 장식용 가짜 차트. 7호의 계단 차트는 서로 다른 플랫폼 순위를 이어 붙여
  연속 상승처럼 보이게 했고, 시간축 간격도 실제 날짜 간격과 비례하지 않았다.
- 그림 안에 박아 넣은 글자(헤드라인·숫자). 오탈자 검수가 어렵고 스크린리더가 읽지 못한다.

### 그림 원칙
- 데이터는 코드로 그린 실제 차트로 낸다. 축 간격은 실제 값에 비례, 다른 기준(플랫폼·시각)은 섞지 않거나 구분해 표시.
- 생성 일러스트는 이슈당 1장까지. 캡션 끝에 "· 일러스트: AI 생성"을 단다.
- 차트 캡션은 "자료:"로 시작해 출처와 기준 시각을 쓴다. 예: "자료: 멜론·유튜브 차트, 톱스타뉴스 뮤직100, CWN". 출처에 없는 "종가" 같은 말은 붙이지 않는다("등락률").
- alt에는 차트가 보여 주는 내용과 숫자를 그대로 적는다.
- 참고 관행: AP·가디언은 AI 생성 이미지를 쓸 때 명시하고 출처를 캡션에 단다. 국내 언론은
  "사진=유튜브 캡처", "일러스트｜챗GPT"처럼 크레디트를 붙인다.

## 3. 발행 전 점검

- [ ] 모든 숫자에 출처가 refs에 있고, 순위·주가에는 기준 시각이 있다. 확인 못 한 숫자는 뺀다.
- [ ] 인용과 평가에 말한 사람 이름이 붙어 있다. 인과 표현은 출처가 직접 말한 것이다.
- [ ] 이미지 속 글자(날짜·라벨)와 본문·캡션 표현이 같다(7호: "9.22 국회 토론회").
- [ ] 제목은 사실 헤드라인, 요점은 한 줄 한 사실, 인트로 끝 문장은 사실이다.
- [ ] 차트 캡션은 "자료:"로 시작하고, 생성 일러스트는 1장 이하에 "일러스트: AI 생성" 표기가 있다.
- [ ] 아래 카운트(최신 이슈 `issues[0]` 본문만, 레포 루트에서)를 돌려 기준을 넘지 않는다.

```bash
python -c "import json,sys;sys.stdout.reconfigure(encoding='utf-8');i=json.load(open('news/issues.json',encoding='utf-8'))['issues'][0];t=json.dumps({k:i.get(k) for k in('intro','highlights','feature','body')},ensure_ascii=False);[print(p,t.count(p)) for p in['—','**','아니라','더 이상','흔들','무겁','무거운','단단','움직였','물러섰','빈칸','미끄러','붙었다','정리됐','전망이다','주목','평이다','때문에']]"
```

| 패턴 | 기준 |
|---|---|
| `—` | 2 이하 (이슈 제목의 것 포함) |
| `**` | 꼭지 수 × 2 이하, 숫자에만 |
| `아니라`, `더 이상` | 0 |
| `흔들` `무겁` `무거운` `단단` `움직였` `물러섰` `빈칸` `미끄러` | 0 |
| `붙었다` `정리됐` `전망이다` `주목` `평이다` `때문에` | 0, 남으면 문맥 확인 |
